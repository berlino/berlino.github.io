## Setup

```bash
jekyll build
bundle exec jekyll serve
```

Also, see this [early blog post](https://karpathy.github.io/2014/07/01/switching-to-jekyll/) on how to use Jekyll. Adapted from [al folio](https://github.com/alshedivat/al-folio).


## Trouble-shotting

* run `bundle exec jekyll serve` to removes every system gem not in this bundle.
